## `$ whoami` — About Me

<img align="right" width="175" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="Animated developer coding" />

Hey there! I'm **Rauf Ahmad**, a Computer Science graduate from Pakistan with a **CGPA of 3.88/4.00**, passionate about engineering reliable software and exploring intelligent systems.

I build full-stack web applications, cross-platform desktop software, and data-driven solutions. My experience spans frontend engineering, backend APIs, databases, authentication, role-based systems, and third-party integrations.

- 🎯 **Long-term direction:** Software engineering and advanced AI/ML
